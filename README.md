\# 🎨 ArtVault



ArtVault is a Streamlit-based digital art exhibition platform designed to provide an interactive way to explore, discover, and analyze artworks through a clean and user-friendly interface.



The application combines artwork discovery, search, filtering, detailed artwork views, ratings, and visual analytics into a single web application.



\## ✨ Features



\* 🖼️ \*\*Artwork Collection\*\* — Browse a curated collection of 30 artworks.

\* 🔎 \*\*Search \& Filtering\*\* — Find artworks by name, artist, category, medium, country, or art movement.

\* 📋 \*\*Artwork Details\*\* — Explore individual artwork information including artist, year, medium, country, rating, and price.

\* 📊 \*\*Analytics Dashboard\*\* — Visualize artwork and collection-level insights.

\* ⭐ \*\*Ratings \& Reviews\*\* — Display artwork ratings and user-oriented engagement features.

\* 🎨 \*\*Image Gallery\*\* — Uses locally stored artwork images for an exhibition-style browsing experience.

\* 📱 \*\*Interactive UI\*\* — Built with Streamlit for a responsive and accessible web interface.

\## 🚀 Getting Started



\### 1. Clone the repository



```bash

git clone https://github.com/OshinNandwal/ArtVault.git

cd ArtVault

```



\### 2. Install dependencies



```bash

pip install streamlit pandas matplotlib

```



\### 3. Run the application



```bash

streamlit run app.py

```



The application will open in your browser at the local Streamlit address.

\## 🎯 Project Objective



The objective of ArtVault is to demonstrate how Python, data handling, visualization, and Streamlit can be combined to build an interactive digital platform around structured art data.



The project focuses on creating an engaging user experience while demonstrating practical skills in data-driven application development.
